Fonte e escopo

Snapshot real retornado pela API Omie em modo somente leitura. Esta versão publica apenas agregações por empresa, natureza e situação; o detalhe operacional permanece no dashboard local protegido.

Fórmulas

  • Valor exibido: valor liquidado para títulos encerrados; valor do documento para os demais.
  • Saldo pendente: máximo entre valor do documento menos valor pago e zero.
  • A vencer: a vencer + vence hoje.
