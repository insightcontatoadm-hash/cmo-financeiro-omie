# CMO Financeiro

Dashboard público executivo da CMO, publicado em modo somente leitura.

## Escopo público

Esta edição apresenta somente agregações por empresa, natureza e situação, derivadas de um snapshot real da API Omie. Não são publicados títulos individuais, nomes de clientes, IDs, observações, credenciais ou dados de acesso.

O painel é um snapshot e não realiza atualização automática em tempo real. O detalhamento operacional permanece no ambiente local protegido.
